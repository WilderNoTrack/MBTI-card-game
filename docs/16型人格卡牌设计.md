# 人格对战卡牌游戏 — 16型完整卡组设计

## 基础规则速查
- 初始生命值：10
- 代价槽上限：10（满则输）
- 公开度范围：0-10
- 共鸣值：与对手的连接强度
- 每人手牌：5张基础牌 + 1张隐藏技能牌（AI生成）
- 隐藏技能激活条件：公开度 ≥ 7

---

## 卡牌格式说明
每张牌包含：
- **效果**：具体机制
- **代价**：代价槽变化（+N 为增加，-N 为降低）
- **公开度**：公开度变化

# 隐藏技能牌系统

## 生成规则

每位玩家在游戏开始前回答2个问题：

**问题1**：一件你始终忘不了的事
**问题2**：你最想隐藏的一面是什么

Claude根据回答生成专属隐藏技能牌，格式如下：

```
【牌名】由经历意象提炼
【激活条件】公开度 ≥ 7
【发动方式】玩家需要大声说出问题1的答案（可隐喻）
```
