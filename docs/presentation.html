AI Integration

Claude AI · 专属卡牌引擎

生成流程
👤
玩家输入
MBTI类型 + 回答内容 + 深度层级
↓
🤖
Claude API (Sonnet)
分析人格特征 → 生成符合稀有度的卡牌效果
↓
🃏
专属卡牌
名称 + 效果描述 + effect_code + 数值参数

⚙️ AI约束机制

AI只能从预设效果池中选择变体，
代价/公开度受稀有度严格限制，
确保游戏平衡不被破坏。

🛡️ Fallback保障

Claude返回非JSON或格式错误时，
自动使用预设fallback卡牌，
绝不让游戏卡住。

🌟 隐藏技能触发

公开度≥7，玩家大声念出第5轮回答内容时激活。这一刻是游戏的情感高潮。
